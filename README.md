# longtable-media

Static media served by GitHub Pages for Longtable Labs apps. Public, because
GitHub Pages on a free account requires it; everything here is already public
(the videos are the ones posted daily on TikTok).

- `ads/manifest.json` and `ads/<id>.ogv`: the house-ad rotation read by the
  `house_ads` Godot addon (repo granttyreit-hub/house-ads). Written only by
  `house-ads/tools/publish_video.py`; do not edit by hand.
